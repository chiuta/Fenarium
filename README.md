**Atlas and workshop of phenes: subjective perceptions across all senses, starting from Phosphenism.**

Version: 9.1.0 · Last updated: 3 November 2026

## What it is

FENARIUM is a single-file, offline HTML app: an atlas of subjective perceptions (phosphenes, tinnitus-like sounds, afterimages, motion aftereffects and more) across vision, hearing, touch, movement, taste, smell, interoception and time. It starts from Francis Lefebure's Phosphenism, presented as practitioners' claims next to what science supports, and adds a detailed 13-module course, guided experiments, a visual simulator, a self-experiment laboratory (randomised A/B with an exact paired permutation test, blind Zwicker series with d′), a journal, a quiz, a timeline, a glossary and verified news (as of 2 November 2026).

## Use

Open index.html in any modern browser. No installation, no account, no tracking; data stays in your browser (localStorage). The language selector is in the top bar (English, Română, Français, Italiano, Español, Português, Deutsch, Magyar). Online: https://fenarium.chiuta.ro. The layout adapts to desktop (side menu), tablet and mobile (wrapping menu, no scrolling). Click the version label for the Transparency dialog (network, storage, `.fff.json` backup, sync between your devices). Since 9.1.0 the data keys are named `fenarium.*`; keys from earlier versions (`fenarium_*`) are copied automatically on first start and left untouched. The interface has 8 languages; translations other than Romanian are automatic and not reviewed by native speakers.

## Safety and limits

Educational material, not a medical device: it does not diagnose, treat or prevent anything. Light exercises are not for people with photosensitive epilepsy; read the Safety section. Sources and limits are listed inside the app.
